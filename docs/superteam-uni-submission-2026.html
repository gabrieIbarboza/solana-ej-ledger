Descrição para colar no Superteam Earn

Empresas Juniores têm regras internas de despesas, mas o reembolso ainda costuma depender de mensagens no WhatsApp, planilhas e checagem manual. Para um estudante, é difícil saber antes se uma despesa será aceita. Para quem administra, é difícil manter uma trilha clara de decisões e comprovantes. O EJ Ledger transforma o RID — Regulamento Interno de Despesas — em regras digitais versionadas. Quando um aluno descreve uma despesa, nossa API e SDK retornam uma decisão objetiva: aprovada, bloqueada ou pendente de aprovação. O mesmo núcleo pode ser usado por um site, WhatsApp, Telegram ou outro canal; o bot apenas conversa com o aluno e nunca decide a regra por conta própria. No MVP, o aluno confirma os dados da despesa, recebe a decisão e, se ela for aprovada, anexa o comprovante. O sistema cria uma prova na Solana devnet com hashes da política, da despesa e do comprovante. Nenhum dado sensível — valores, finalidade, conversa ou arquivo — vai para a blockchain. O histórico compartilhado mostra as provas públicas da organização; uma futura camada de banco de dados conectará esses hashes aos documentos e relatórios off-chain autorizados. Usamos Solana porque a prova tem baixo custo e pode ser verificada de forma independente, vinculada à versão exata da regra aplicada. Não usamos blockchain para substituir o RID nem para fazer transferência de dinheiro: usamos como camada de evidência auditável para uma realidade universitária brasileira. O MVP já possui interface web, integração de carteira, API/SDK e bot de WhatsApp em ambiente de demonstração.
